# Svb_Byd_Deck_Auto_Memory
### 《Shadowverse: Worlds Beyond》自动化助手 (内存直读增强版)

一个专为《Shadowverse: Worlds Beyond》打造的高性能自动化战斗助手。在传统图色识别的基础上，深度内嵌了**原生内存直读引擎**、**动态特征码逆向自愈系统**、**桌面分身（真·后台免打扰）**与**战场态势实时看板**，实现零延迟、免外部依赖、超精准的战斗与打牌自动化。

</div>

---

## ⚡ 核心亮点 (四大硬核特性)

- 🚀 **内嵌内存直读（免外部工具，零延迟）**：
  无需额外运行外部记牌器或多余工具，程序进程内直读游戏 IL2CPP 内存，微秒级获取回合、生命值、PP、EP 及敌我手牌详情。
- 🖥️ **桌面分身（真·后台免打扰，完全不抢物理鼠标）**：
  内置 Windows Child Session 虚拟桌面隔离引擎（由 `tools/desktop_avatar/DesktopAvatar.exe` 驱动）。在后台创建完全隔离的独立 Windows 会话，游戏与自动化脚本在子桌面中安静运行，物理机鼠标键盘完全自由，办公打牌两不误！
- 🔮 **动态特征码逆向与一键自愈**：
  基于 Unity IL2CPP 物理结构算法，游戏版本更新后可由程序自动或在 GUI 界面一键动态逆向扫描提取 RVA 偏移（约 7 秒），自动生成并更新配置文件，告别因游戏更新导致的失效。
- 📊 **战场态势与随从状态看板**：
  主界面新增实时态势面板，秒级展示敌我双方随从/护符属性（攻/防）、关键词（守护/疾驰/突进等）以及动态攻击走脸权限（`[可打脸]` / `[仅随从]`）。
- 🎴 **物理抛物线手牌推算与动态减费识别**：
  通过游戏原生扇形抛物线算法精准计算每张手牌点击坐标；直接读取被减费后的真实打出费用，支持本体/结晶/激奏形态智能识别。
- 🛡️ **双引擎智能兜底**：
  内存模式与传统图色模式无缝融合，若因切屏等极端情况未能获取内存，自动平滑回退至 OpenCV 模板匹配与 SIFT 识别，稳定不中断。

## 功能一览

### 战斗与策略
- **内存直读出牌与攻击**：精准判定费用与攻击目标，告别手牌反光遮挡或漏识问题。
- **换牌策略**：提供 3 费、4 费、5 费等档次的换牌策略，优化起手手牌。
- **特殊卡牌效果**：支持卡牌二选一、指定目标、抉择与增益等复杂效果编辑器。
- **进化与超进化**：根据场面优劣势、EP 与点数智能分配进化时机。
- **庆典模式与空过**：支持庆典广场赛自动化流程与快捷空过功能。
- **运行终止控制**：支持按运行时长或目标胜场停止，结算后安全关闭游戏。

### 桌面分身 (Child Session)
- **物理输入完全解脱**：子桌面会话拥有独立的虚拟输入上下文，无论前台在全屏打游戏、看视频还是办公写代码，鼠标都不会被拉走或抢占。
- **高画质与缩放适配**：分身窗口提供 1:1 视口渲染与多档分辨率切换（1920x1080 / 1280x720 等），画面清晰细腻。

### 卡组与卡牌库
- **卡组管理**：支持保存、加载、分享卡组及扫描官方二维码。
- **本地卡牌库**：支持按职业、费用、卡包和稀有度筛选，并可手动检查官方清单进行增量更新。

### 图形界面 (GUI)
- **特征码状态感知**：实时显示当前游戏版本特征码匹配状态（🟢 匹配 / 🟠 未适配 / ⚪ 未运行），支持 GUI 一键更新。
- **设备与窗口选择**：原生支持 Windows Graphics Capture (WGC) 窗口捕获与 Android ADB 连接。
- **实时日志与数据看板**：对战次数、运行时长、卡牌分布及实时日志同屏展示。

## 🖥️ 桌面分身 (真·后台) 使用指南

“桌面分身”是专为希望**“电脑挂着打牌、自己正常用电脑”**的用户设计的黑科技功能：

1. **功能入口**：
   在 GUI 左侧菜单栏切换到 **【桌面分身】**（或主页点击“启动桌面分身”）。
2. **选择分辨率**：
   弹出对话框中选择虚拟桌面的初始分辨率（推荐与您的显示器一致，或选用 `1920x1080` / `1280x720`）。
3. **身份凭据认证**：
   * 首次启动时，Windows 系统会弹出一次性登录认证框（属于 Windows 内部安全的本地 Loopback 机制）；
   * 请输入您当前 Windows 账号的登录密码；软件会在本地妥善加密记录，下次启动免输。
4. **分身内启动游戏与脚本**：
   * 桌面分身窗口启动后，会呈现一个纯净的独立 Windows 桌面；
   * 在分身窗口内直接打开 Steam / 影之诗与本脚本助手，即可开始完全不抢鼠标的真正静默挂机！

## 安装与使用

### 普通玩家运行方式

1. 克隆或下载本项目压缩包并解压；
2. 运行环境推荐 Python 3.11，安装锁文件依赖：
   ```powershell
   pip install -r requirements-py311.lock
   ```
3. 启动图形界面：
   ```powershell
   python main_ui.py
   ```
4. **运行推荐配置**：
   * **运行方式**：选择 `WGC (Windows 原生窗口捕获)`
   * **识别方式**：选择 **`内存直读（内置推荐，全面支持Steam国际服）`**
   * 确认识别方式右侧显示 **🟢 特征码匹配**，点击“开始运行”即可。

---

### 服务器环境与适配说明

| 游戏版本/载体 | 运行方式建议 | 识别方式建议 | 说明 |
| :--- | :--- | :--- | :--- |
| **Steam 国际服 (PC 原生)** | WGC 窗口捕获 | **内存直读（强烈推荐）** | **全面深度适配并经过实测**，体验最佳。 |
| **网易国服 (MuMu 桌面高清版)** | WGC 窗口捕获 | 内存直读（需自测） | 网易 PC 独立客户端可尝试使用，若特征码失效可点击“一键提取”。 |
| **国服/国际服 (普通安卓模拟器)** | ADB 连接 | **传统图色识别与 OCR** | 安卓虚拟机内存与宿主机隔离，无法使用内存直读，请使用图色模式。 |

> 💡 **版本更新应对**：
> 当 Steam 游戏推送更新导致特征码不匹配时，保持游戏运行，直接在 GUI 界面“识别方式”旁点击 **【★ 一键提取特征码】**（或终端运行 `python tools/auto_update_profile.py`），约 7 秒后即可自动恢复内存直读！

## 面向开发者的环境与构建

### 1. 开发环境搭建
```powershell
git clone https://github.com/Sagisawa/Svb_Byd_Deck_Auto_Memory.git
cd Svb_Byd_Deck_Auto_Memory

python -m venv .venv
.venv\Scripts\activate

pip install -r requirements-py311.lock
```

### 2. 运行入口
* **GUI 界面入口**：
  ```powershell
  python main_ui.py
  ```
* **CLI 命令行入口**：
  ```powershell
  python main.py
  ```

### 3. 一键特征码提取小工具
游戏在后台运行时，可单独运行特征码提取工具进行离线测试与配置生成：
```powershell
python tools/auto_update_profile.py
```

### 4. 项目结构

```text
Svb_Byd_Deck_Auto_Memory/
├── main.py                    # CLI 入口
├── main_ui.py                 # GUI 入口
├── tools/                     # 工具集
│   ├── auto_update_profile.py # 游戏版本特征码动态逆向提取脚本
│   └── desktop_avatar/        # C# 实现的 Windows Child Session 桌面分身引擎
│       ├── DesktopAvatar.exe  # 桌面分身二进制程序
│       └── src/               # 分身宿主与 RDP 本地环回源码
├── src/                       # 核心源码目录
│   ├── tracker/               # 内存直读引擎核心 (Il2Cpp内存扫描、版本档案、数据模型)
│   │   ├── memory/            # Win32读写封装、Il2Cpp类查找与战场数据解码
│   │   └── version_profiles/  # 游戏版本 RVA 特征码配置文件库
│   ├── bridge/                # 内存直读与上层战斗逻辑的桥接适配器
│   ├── device/                # 设备连接 (WGC / ADB)、窗口管理与子会话调度
│   │   └── child_session/     # 桌面分身管理器与凭据生命周期控制
│   ├── app/                   # 应用启动与组合入口
│   ├── config/                # 配置管理、路径与策略配置
│   ├── core/                  # 日志、运行控制等核心基础能力
│   ├── game/                  # 战斗逻辑、卡牌效果引擎与策略执行
│   └── ui/                    # PyQt5 图形界面与工作线程
├── templates/                 # 国服图色模板
├── templates_global/          # 国际服图色模板
├── models/                    # OCR 与 MNIST 模型
├── docs/                      # 用户与开发文档
└── requirements-py311.lock    # Python 依赖锁定文件
```

### 5. 打包与发布
```powershell
pip install -r requirements-py311.lock
pip install -r requirements-build.in
pyinstaller main.spec
```
